Lesson 16: Analyze and Prepare Hemoglobin Data for Visualization

Create descriptive summaries, distribution data, record counts, and missingness tables for professional figures

Analyze hemoglobin across NHANES survey cycles and prepare validated datasets for four publication-style visualizations.
NoteLearning objectives

By the end of this lesson, you should be able to:

  • load the saved analysis-ready dataset;
  • define the hemoglobin analytical population;
  • document inclusion and exclusion criteria;
  • summarize hemoglobin overall;
  • summarize hemoglobin by survey cycle and sex;
  • calculate descriptive intervals around unweighted means;
  • prepare participant-level data for a distribution figure;
  • prepare analytical record counts by cycle and sex;
  • summarize hemoglobin missingness by cycle and sex;
  • create scale recommendations for the principal trend figure;
  • validate every visualization dataset;
  • save the tables required for Lesson 17.

What this lesson prepares

Lesson 17 will use the outputs from this lesson to create four figures:

  1. Mean hemoglobin trend by survey cycle and sex
  2. Hemoglobin distribution by survey cycle and sex
  3. Analytical record counts by survey cycle and sex
  4. Hemoglobin missingness by survey cycle and sex

The first figure will be the principal result.

The remaining figures will help learners evaluate:

  • the underlying distribution;
  • the number of records contributing to each mean;
  • whether missingness changes across cycles;
  • whether a mean-only figure hides important information.

Important statistical scope

All summaries in this lesson are:

unweighted descriptive summaries

They describe the analytical records in the dataset.

They are not automatically nationally representative.

Formal NHANES population estimates require:

  • the appropriate examination or subsample weight;
  • SDMVSTRA;
  • SDMVPSU;
  • correct multi-cycle weight construction;
  • complex-survey variance estimation.
WarningDo not describe these results as national estimates

The analyses in this lesson are designed to demonstrate the completed data pipeline and prepare professional exploratory figures.

They should be described as:

unweighted descriptive summaries of the analytical records

They should not be described as:

nationally representative hemoglobin estimates

WarningA review flag is not an exclusion rule

The broad thresholds in this lesson are used to identify records for inspection.

They should not be used to remove records automatically.

An unusual value may reflect:

  • a true extreme result;
  • a measurement issue;
  • a coding problem;
  • a unit problem;
  • a laboratory-method difference;
  • a source-data problem.

Create a safe descriptive-summary function

Add:

summarize_hemoglobin <- function(
    data) {

  nonmissing_values <- data$LBXHGB[
    !is.na(
      data$LBXHGB
    )
  ]

  if (
    length(
      nonmissing_values
    ) == 0
  ) {
    return(
      tibble::tibble(
        records = nrow(
          data
        ),
        nonmissing_hemoglobin = 0L,
        mean_hemoglobin = NA_real_,
        standard_deviation = NA_real_,
        standard_error = NA_real_,
        minimum = NA_real_,
        first_quartile = NA_real_,
        median_hemoglobin = NA_real_,
        third_quartile = NA_real_,
        maximum = NA_real_
      )
    )
  }

  records <- length(
    nonmissing_values
  )

  standard_deviation <- if (
    records > 1
  ) {
    stats::sd(
      nonmissing_values
    )
  } else {
    NA_real_
  }

  standard_error <- if (
    records > 1
  ) {
    standard_deviation /
      sqrt(
        records
      )
  } else {
    NA_real_
  }

  tibble::tibble(
    records = nrow(
      data
    ),
    nonmissing_hemoglobin =
      records,
    mean_hemoglobin =
      mean(
        nonmissing_values
      ),
    standard_deviation =
      standard_deviation,
    standard_error =
      standard_error,
    minimum =
      min(
        nonmissing_values
      ),
    first_quartile =
      stats::quantile(
        nonmissing_values,
        probabilities = 0.25,
        names = FALSE
      ),
    median_hemoglobin =
      stats::median(
        nonmissing_values
      ),
    third_quartile =
      stats::quantile(
        nonmissing_values,
        probabilities = 0.75,
        names = FALSE
      ),
    maximum =
      max(
        nonmissing_values
      )
  )
}

Why the intervals are called descriptive intervals

The calculation:

mean ± 1.96 × standard error

treats the records as though they came from a simple random sample.

NHANES uses a complex, multistage survey design.

The variables in this lesson are therefore named:

lower_descriptive_95
upper_descriptive_95

rather than simply:

lower_95
upper_95

This reduces the risk that learners will mistake them for survey-adjusted confidence intervals.

Prepare scale recommendations for the principal figure

The principal graph should use a scale based on the observed descriptive intervals rather than an arbitrary range.

Calculate the displayed minimum and maximum:

trend_interval_minimum <- min(
  hemoglobin_trend_figure_data$lower_descriptive_95,
  na.rm = TRUE
)
trend_interval_maximum <- max(
  hemoglobin_trend_figure_data$upper_descriptive_95,
  na.rm = TRUE
)

Add a small amount of visual space:

trend_axis_padding <- max(
  0.5,
  0.10 *
    (
      trend_interval_maximum -
        trend_interval_minimum
    )
)

Create recommended limits:

trend_y_axis_lower <- floor(
  (
    trend_interval_minimum -
      trend_axis_padding
  ) *
    2
) /
  2
trend_y_axis_upper <- ceiling(
  (
    trend_interval_maximum +
      trend_axis_padding
  ) *
    2
) /
  2

Choose an appropriate break interval:

trend_y_axis_range <-
  trend_y_axis_upper -
    trend_y_axis_lower
trend_y_axis_break <- dplyr::case_when(
  trend_y_axis_range <= 3 ~
    0.5,

  trend_y_axis_range <= 8 ~
    1,

  trend_y_axis_range <= 15 ~
    2,

  TRUE ~
    5
)

Create a scale summary:

hemoglobin_trend_scale_recommendation <-
  tibble::tibble(
    observed_interval_minimum =
      trend_interval_minimum,
    observed_interval_maximum =
      trend_interval_maximum,

      trend_y_axis_lower,

      trend_y_axis_upper,

ImportantA focused y-axis must be transparent

The principal trend graph may use a focused range because it is intended to show relatively small differences in mean hemoglobin.

To avoid misleading readers:

  • the axis must be clearly numbered;
  • the scale must be based on the observed data;
  • the caption must identify the descriptive scope;
  • the figure must not imply that zero is the meaningful reference point;
  • the selected limits must not hide any mean or interval.

How to describe the results

Appropriate language:

Hemoglobin was summarized descriptively among complete analytical records
by two-year NHANES survey cycle and sex. All results are unweighted.

Avoid:

National hemoglobin levels increased or decreased over time.

That statement would require correctly weighted complex-survey analysis.

Interpretation framework

When reviewing the figures in Lesson 17, consider:

  1. whether mean and median patterns agree;
  2. whether distributional spread changes across cycles;
  3. whether extreme observations influence the means;
  4. whether the male-female difference is consistent;
  5. whether group sizes differ substantially;
  6. whether missingness changes across cycles;
  7. whether laboratory methods or eligibility changed;
  8. whether survey-weighted estimates would differ;
  9. whether the observed pattern is descriptively important;
  10. whether formal inferential analysis is justified.

Common mistakes

Preparing only a mean table

A mean does not reveal the full distribution, record count, or missingness pattern.

Reporting descriptive intervals as survey confidence intervals

The intervals in this lesson do not incorporate the NHANES complex sampling design.

Removing extreme values automatically

Flag and investigate unusual values before exclusion.

Ignoring changes in analytical record count

A group mean based on fewer records may be less stable.

Ignoring missingness

Changes in missingness can affect comparisons across cycles.

Using an arbitrary graph scale

The principal figure will use a scale derived from the displayed means and intervals.

Interpreting sex differences causally

The summaries are unadjusted and descriptive.

Describing unweighted records as the U.S. population

National inference requires survey weights and design variables.

Knowledge check

NoteWhy prepare more than one figure?

The mean trend shows the central pattern, but the distribution, record-count, and missingness figures reveal information that a mean-only graph can hide.

NoteWhy are the interval variables named lower_descriptive_95 and upper_descriptive_95?

The names make clear that the intervals are conventional unweighted descriptive intervals rather than NHANES survey-adjusted confidence intervals.

NoteWhy calculate the principal figure scale from the observed data?

A data-informed scale includes all displayed means and intervals, avoids arbitrary choices, and supports a readable figure without hiding observations.

NoteCan a visually polished figure be considered a nationally representative result?

No. Visual quality does not replace appropriate survey weighting, design specification, and complex-survey variance estimation.

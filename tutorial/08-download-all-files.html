Lesson 8: Download All Required NHANES Files

Scale the tested single-file workflow to the complete CBC and Demographic source catalog

Download, validate, and document all CBC and Demographic XPT files used by the pipeline.
NoteLearning objectives

By the end of this lesson, you should be able to:

  • generate official CDC URLs for every catalog row;
  • construct component-specific local file paths;
  • download all declared source files;
  • continue processing while recording individual failures;
  • calculate file sizes and SHA-256 hashes;
  • create a complete acquisition manifest;
  • distinguish downloaded, reused, and failed files;
  • stop the pipeline when required primary sources are unavailable.

Where you are in the workflow

In Lesson 7, you tested the acquisition process with one file:

CBC_J.xpt

You confirmed that the workflow could:

  • contact the official CDC source;
  • download through a temporary .part file;
  • validate the HTTP result;
  • save the file locally;
  • calculate a hash;
  • read the file with haven;
  • confirm that SEQN was present.

You will now apply the same process to all source rows in the catalog.

Expected source count

The source catalog contains:

  • 10 primary CBC files;
  • 1 supplementary second-examination CBC file;
  • 10 primary Demographic files.

Total:

21 source files

Generate official source URLs

The NHANES public-use files in this tutorial follow this structure:

https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/
{cycle_start}/DataFiles/{file_id}.xpt

Create a URL function:

build_nhanes_url <- function(
    cycle_start,
    file_id) {

  if (
    length(cycle_start) != 1 ||
    is.na(cycle_start)
  ) {
    stop(
      "cycle_start must contain one nonmissing value."
    )
  }

  if (
    length(file_id) != 1 ||
    is.na(file_id) ||
    !nzchar(file_id)
  ) {
    stop(
      "file_id must contain one nonempty value."
    )
  }

  paste0(
    "https://wwwn.cdc.gov/",
    "Nchs/Data/Nhanes/Public/",
    cycle_start,
    "/DataFiles/",
    file_id,
    ".xpt"
  )
}

Test it:

build_nhanes_url(
  cycle_start = 2017,
  file_id = "CBC_J"
)

Expected result:

https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/CBC_J.xpt

Construct local destination paths

Create a function that assigns each source to its component folder:

build_local_destination <- function(
    component,
    file_id) {

  component_directory <- dplyr::case_when(
    component == "cbc" ~
      file.path(
        "data",
        "raw",
        "cbc"
      ),

    component == "demographic" ~
      file.path(
        "data",
        "raw",
        "demographic"
      ),

    TRUE ~ NA_character_
  )

  if (is.na(component_directory)) {
    stop(
      "Unsupported component: ",
      component
    )
  }

  file.path(
    component_directory,
    paste0(
      file_id,
      ".xpt"
    )
  )
}

Add destinations to the catalog:

nhanes_catalog <- nhanes_catalog |>
  dplyr::mutate(
    local_destination = purrr::map2_chr(
      component,
      file_id,
      build_local_destination
    )
  )

Create a safe wrapper

The download_nhanes_file() function stops when one file fails.

For a bulk process, we want to:

  • record the failure;
  • continue to the next file;
  • review all results afterward.

Create a safe wrapper:

download_catalog_row <- function(
    dataset_id,
    cycle,
    component,
    file_id,
    analysis_role,
    url,
    local_destination,
    overwrite = FALSE) {

  started_at <- Sys.time()

  result <- tryCatch(
    {
      local_file <- download_nhanes_file(
        url = url,
        destination = local_destination,
        overwrite = overwrite
      )

      file_information <- file.info(
        local_file
      )

      file_hash <- digest::digest(
        local_file,
        algorithm = "sha256",
        file = TRUE
      )

      tibble::tibble(
        dataset_id = dataset_id,
        cycle = cycle,
        component = component,
        file_id = file_id,
        analysis_role = analysis_role,
        source_url = url,
        local_file = local_file,
        status = "success",
        file_size_bytes = unname(
          file_information$size
        ),
        sha256 = file_hash,
        error_message = NA_character_,
        started_at_utc = format(
          started_at,
          tz = "UTC",
          usetz = TRUE
        ),
        completed_at_utc = format(
          Sys.time(),
          tz = "UTC",
          usetz = TRUE
        )
      )
    },
    error = function(error_condition) {
      tibble::tibble(
        dataset_id = dataset_id,
        cycle = cycle,
        component = component,
        file_id = file_id,
        analysis_role = analysis_role,
        source_url = url,
        local_file = local_destination,
        status = "failed",
        file_size_bytes = NA_real_,
        sha256 = NA_character_,
        error_message = conditionMessage(
          error_condition
        ),
        started_at_utc = format(
          started_at,
          tz = "UTC",
          usetz = TRUE
        ),
        completed_at_utc = format(
          Sys.time(),
          tz = "UTC",
          usetz = TRUE
        )
      )
    }
  )

  result
}

Download all catalog sources

Run:

acquisition_manifest <- purrr::pmap_dfr(
  nhanes_catalog |>
    dplyr::select(
      dataset_id,
      cycle,
      component,
      file_id,
      analysis_role,
      url,
      local_destination
    ),
  function(
      dataset_id,
      cycle,
      component,
      file_id,
      analysis_role,
      url,
      local_destination) {

    download_catalog_row(
      dataset_id = dataset_id,
      cycle = cycle,
      component = component,
      file_id = file_id,
      analysis_role = analysis_role,
      url = url,
      local_destination = local_destination,
      overwrite = FALSE
    )
  }
)

This process may take several minutes depending on:

  • internet speed;
  • server response time;
  • whether some files already exist.

Stop when a primary source fails

A failed supplementary source should be reported clearly.

A failed primary source means the main pipeline is incomplete.

Add:

failed_primary_sources <- acquisition_manifest |>
  dplyr::filter(
    status == "failed",
    analysis_role == "primary"
  )

if (nrow(failed_primary_sources) > 0) {
  stop(
    "One or more required primary source files failed to download: ",
    paste(
      failed_primary_sources$dataset_id,
      collapse = ", "
    )
  )
}

Warn when a supplementary source fails

Add:

failed_supplementary_sources <- acquisition_manifest |>
  dplyr::filter(
    status == "failed",
    analysis_role == "supplementary"
  )

if (nrow(failed_supplementary_sources) > 0) {
  warning(
    "One or more supplementary source files failed: ",
    paste(
      failed_supplementary_sources$dataset_id,
      collapse = ", "
    )
  )
}

Rerunning the acquisition

Because the download function uses:

overwrite = FALSE

existing files are reused.

You should see messages such as:

Using existing file: data/raw/cbc/CBC_J.xpt

This makes rerunning the pipeline faster.

Force a full redownload

To deliberately download every file again, change:

overwrite = FALSE

to:

overwrite = TRUE

Do this only when:

  • a local file is suspected to be corrupted;
  • an official file has been revised;
  • you intentionally want a fresh source snapshot.

Why hashes matter across runs

Suppose a file is downloaded again later.

You can compare:

previous SHA-256
current SHA-256

If they differ, the local bytes changed.

That may indicate:

  • an official file revision;
  • corruption;
  • incomplete prior download;
  • a different server response.

A changed hash does not explain why the file changed, but it provides evidence that it did.

Common problems

Some files return HTTP 404

Check:

  • cycle_start;
  • file_id;
  • capitalization;
  • historical naming differences;
  • official component documentation.

Downloads stop after one error

Confirm that the bulk process calls download_catalog_row(), which catches individual errors.

The script stops after completing all attempts

This may be intentional if one or more required primary files failed.

Review:

failed_primary_sources

Fewer than 21 files appear locally

Inspect:

failed_acquisitions

and:

acquisition_manifest

Do not create empty placeholder XPT files to satisfy the count.

A source file already exists

The default behavior is to reuse it.

Set overwrite = TRUE only when replacement is intentional.

A file has a zero-byte size

Delete it and rerun the download. It should not be treated as a valid source.

Knowledge check

NoteWhy catch errors separately for each source?

It allows the pipeline to attempt every declared source and produce one complete failure report instead of stopping at the first problem.

NoteWhy should a failed primary source stop the pipeline?

The main analytical dataset would be incomplete, so later combination and trend analyses should not proceed as though all required cycles were present.

NoteWhat is the purpose of the acquisition manifest?

It records what was requested, what succeeded, where files were saved, their sizes and hashes, and any errors encountered.

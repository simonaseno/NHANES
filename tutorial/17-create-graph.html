Lesson 17: Create Professional Hemoglobin Figures

Build, annotate, validate, export, and display four publication-style visualizations

Create a professional hemoglobin trend figure and supporting distribution, record-count, and missingness figures.
NoteLearning objectives

By the end of this lesson, you should be able to:

  • create a reusable publication-style ggplot2 theme;
  • use a pure white background without gridlines;
  • use color and shape together to distinguish groups;
  • apply a transparent, data-informed vertical scale;
  • create a principal mean-trend figure;
  • display descriptive interval bars;
  • add an explicit in-figure caveat;
  • create supporting distribution, record-count, and missingness figures;
  • validate the data used in every graph;
  • save figures as PNG, PDF, and SVG files;
  • display generated figures directly inside a Quarto lesson;
  • distinguish professional presentation from valid survey inference.

Figures created in this lesson

This lesson creates four complementary figures.

Figure 1: Mean hemoglobin trend

The principal figure displays:

  • unweighted mean hemoglobin;
  • ten NHANES survey cycles;
  • separate male and female trends;
  • conventional descriptive intervals;
  • a focused but transparent vertical scale;
  • a prominent unweighted-analysis caveat.

Figure 2: Hemoglobin distributions

The distribution figure displays:

  • participant-level values;
  • medians;
  • interquartile ranges;
  • distributional spread;
  • possible extreme observations.

Figure 3: Analytical record counts

The record-count figure shows how many complete records contribute to each cycle-sex mean.

Figure 4: Hemoglobin missingness

The missingness figure shows the percentage of records without hemoglobin values by cycle and sex.

Important statistical scope

Every figure in this lesson is based on:

unweighted descriptive analysis

The figures do not incorporate:

  • NHANES survey weights;
  • masked variance strata;
  • masked primary sampling units;
  • multi-cycle weight construction;
  • complex-survey variance estimation.
WarningProfessional appearance does not make a result nationally representative

A figure can be visually suitable for a manuscript draft while still requiring additional statistical work.

These figures describe the analytical records and must not be presented as national population estimates.

Create a publication-style theme

Create a reusable theme:

theme_hemoglobin_publication <- function(
    base_size = 11,
    base_family = "") {

  ggplot2::theme_classic(
    base_size = base_size,
    base_family = base_family
  ) +
    ggplot2::theme(
      plot.background =
        ggplot2::element_rect(
          fill = "white",
          color = NA
        ),
      panel.background =
        ggplot2::element_rect(
          fill = "white",
          color = NA
        ),
      legend.background =
        ggplot2::element_rect(
          fill = "white",
          color = NA
        ),
      legend.key =
        ggplot2::element_rect(
          fill = "white",
          color = NA
        ),
      panel.grid.major =
        ggplot2::element_blank(),
      panel.grid.minor =
        ggplot2::element_blank(),
      plot.title.position =
        "plot",
      plot.caption.position =
        "plot",
      plot.title =
        ggplot2::element_text(
          face = "bold",
          size = base_size + 5,
          margin = ggplot2::margin(
            b = 6
          )
        ),
      plot.subtitle =
        ggplot2::element_text(
          size = base_size + 1,
          lineheight = 1.1,
          margin = ggplot2::margin(
            b = 12
          )
        ),
      axis.title =
        ggplot2::element_text(
          face = "bold",
          size = base_size + 1
        ),
      axis.title.x =
        ggplot2::element_text(
          margin = ggplot2::margin(
            t = 10
          )
        ),
      axis.title.y =
        ggplot2::element_text(
          margin = ggplot2::margin(
            r = 10
          )
        ),
      axis.text =
        ggplot2::element_text(
          color = "black",
          size = base_size
        ),
      axis.text.x =
        ggplot2::element_text(
          angle = 35,
          hjust = 1,
          vjust = 1
        ),
      axis.line =
        ggplot2::element_line(
          color = "black",
          linewidth = 0.55
        ),
      axis.ticks =
        ggplot2::element_line(
          color = "black",
          linewidth = 0.5
        ),
      axis.ticks.length =
        grid::unit(
          2.5,
          "mm"
        ),
      legend.position =
        "top",
      legend.justification =
        "left",
      legend.title =
        ggplot2::element_text(
          face = "bold"
        ),
      legend.text =
        ggplot2::element_text(
          size = base_size
        ),
      legend.spacing.x =
        grid::unit(
          4,
          "mm"
        ),
      plot.caption =
        ggplot2::element_text(
          hjust = 0,
          size = base_size - 1,
          lineheight = 1.15,
          margin = ggplot2::margin(
            t = 12
          )
        ),
      plot.margin =
        ggplot2::margin(
          t = 16,
          r = 18,
          b = 16,
          l = 18
        )
    )
}

Why use a custom theme?

The custom theme provides:

  • a pure white figure background;
  • no horizontal or vertical gridlines;
  • black axis lines and ticks;
  • clear title hierarchy;
  • readable axis labels;
  • consistent legend placement;
  • adequate margins for publication and export.

It also ensures that all four figures share the same visual identity.

Before publication, compare the variable label and unit with the documentation for every included survey cycle.

A common variable name does not by itself prove that methods and units remained unchanged.

Create the principal figure

Run:

hemoglobin_trend_plot <-
  ggplot2::ggplot(
    hemoglobin_trend_figure_data,
    ggplot2::aes(
      x = survey_cycle_factor,
      y = mean_hemoglobin,
      group = sex,
      color = sex,
      shape = sex
    )
  ) +
  ggplot2::geom_errorbar(
    ggplot2::aes(
      ymin = lower_descriptive_95,
      ymax = upper_descriptive_95
    ),
    width = 0.12,
    linewidth = 0.55,
    position = ggplot2::position_dodge(
      width = 0.16
    )
  ) +
  ggplot2::geom_line(
    linewidth = 1.05,
    position = ggplot2::position_dodge(
      width = 0.16
    )
  ) +
  ggplot2::geom_point(
    size = 3.1,
    stroke = 0.8,
    position = ggplot2::position_dodge(
      width = 0.16
    )
  ) +
  ggplot2::annotate(
    geom = "label",
    x = trend_annotation_x,
    y = trend_annotation_y,
    label = trend_caveat_text,
    hjust = 0,
    vjust = 1,
    size = 3.25,
    fontface = "bold",
    lineheight = 1.05,
    fill = "white",
    color = "black",
    label.size = 0.4,
    label.padding = grid::unit(
      0.18,
      "lines"
    )
  ) +
  ggplot2::scale_color_manual(
    values = hemoglobin_palette,
    breaks = c(
      "Male",
      "Female"
    )
  ) +
  ggplot2::scale_shape_manual(
    values = hemoglobin_shapes,
    breaks = c(
      "Male",
      "Female"
    )
  ) +
  ggplot2::scale_y_continuous(
    breaks = seq(
      trend_y_axis_lower,
      trend_y_axis_upper,
      by = trend_y_axis_break
    ),
    labels = scales::label_number(
      accuracy = 0.1
    ),
    expand = ggplot2::expansion(
      mult = c(
        0,
        0
      )
    )
  ) +
  ggplot2::coord_cartesian(
    ylim = c(
      trend_y_axis_lower,
      trend_y_axis_upper
    ),
    clip = "off"
  ) +
  ggplot2::labs(
    title =
      "Mean Hemoglobin Concentration Across NHANES Survey Cycles",
    subtitle =
      "Unweighted descriptive means by sex, 1999–2018",
    x =
      "NHANES two-year survey cycle",
    y =
      hemoglobin_y_axis_label,
    color =
      "Sex",
    shape =
      "Sex",
    caption =
      paste(
        "Figure 1.",
        "Points represent unweighted group means and error bars represent conventional",
        "mean ± 1.96 standard-error intervals.",
        "The analysis does not incorporate NHANES sampling weights, SDMVSTRA,",
        "SDMVPSU, or complex-survey variance estimation.",
        "Results describe the analytical records and are not nationally representative."
      )
  ) +
  theme_hemoglobin_publication(
    base_size = 11
  )

Why this figure is more publication-ready

The figure uses:

  • a white background;
  • no gridlines;
  • distinct color and shape encoding;
  • clearly labelled units;
  • readable chronological cycles;
  • restrained line and point sizes;
  • a data-informed vertical scale;
  • an explicit in-figure warning;
  • a detailed scientific caption.

Understand the focused y-axis

The y-axis is intentionally based on the observed means and intervals.

It does not begin at zero because zero is not the analytical reference point for comparing hemoglobin means.

However, the focused scale must be interpreted carefully because it makes small differences easier to see.

The complete axis values and all intervals remain visible.

Figure 2: Hemoglobin distributions

Why examine distributions?

Two groups can have similar means but very different:

  • medians;
  • spreads;
  • skewness;
  • extreme values;
  • interquartile ranges.

The distribution figure helps prevent overreliance on the mean trend.

The number of records contributing to a mean can vary by:

Displaying record counts helps readers interpret changes in precision and group coverage.

Figure 4: Hemoglobin missingness

Why visualize missingness?

A trend can be influenced by which records are available.

Missingness may change because of:

  • eligibility;
  • specimen collection;
  • examination completion;
  • laboratory availability;
  • release structure;
  • data quality.

The missingness figure helps readers evaluate whether availability differs across cycles or sex groups.

How to evaluate the principal figure

Check whether:

  • all ten survey cycles appear;
  • cycles are in chronological order;
  • male and female groups are clearly distinguishable;
  • color and shape mappings agree;
  • all interval bars are visible;
  • the white background is clean;
  • no gridlines appear;
  • the y-axis values are transparent;
  • the unit is clearly stated;
  • the unweighted caveat is visible inside the figure;
  • the caption explains the interval calculation;
  • the caption states that the results are not nationally representative.

How the four figures work together

Figure 1 answers:

How do the unweighted group means change across cycles?

Figure 2 answers:

What do the underlying distributions look like?

Figure 3 answers:

How many records contribute to each mean?

Figure 4 answers:

Does hemoglobin missingness vary across cycles or sex groups?

No single figure provides the complete analytical picture.

Appropriate reporting language

A suitable principal-figure description is:

Figure 1 presents unweighted mean hemoglobin concentration among complete
analytical records by two-year NHANES survey cycle and sex. Error bars
represent conventional mean ± 1.96 standard-error intervals and do not
incorporate NHANES survey weights, strata, primary sampling units, or
complex-survey variance estimation.

A suitable overall figure-set description is:

The four figures jointly summarize unweighted mean patterns, participant-level
distributions, analytical record counts, and hemoglobin missingness. They are
descriptive outputs of the pipeline and should not be interpreted as nationally
representative estimates.

What would be needed for journal submission?

Before presenting Figure 1 as an inferential NHANES result, the analysis should be extended to include:

  • the correct examination or component-specific survey weight;
  • multi-cycle weight adjustment;
  • SDMVSTRA;
  • SDMVPSU;
  • a survey-design object;
  • survey-adjusted means;
  • design-based standard errors;
  • survey-adjusted confidence intervals;
  • analysis of relevant age or eligibility restrictions;
  • review of laboratory-method comparability;
  • a documented statistical analysis plan.

The visual design can then be retained while replacing the unweighted means and intervals with survey-adjusted estimates.

Common mistakes

Using theme_minimal()

A publication figure does not require theme_minimal().

This lesson uses a custom theme with:

  • white backgrounds;
  • no gridlines;
  • visible axis lines;
  • carefully controlled text and margins.

Using color alone

Color can be difficult to distinguish for some readers or in grayscale printing.

Use both:

color + shape

Omitting the unit

The y-axis should state the verified hemoglobin unit.

Hiding intervals with an unsuitable scale

Every mean and interval must fit within the displayed range.

Beginning the y-axis at zero automatically

A zero baseline is essential for many bar charts, but it is not always analytically necessary for a mean-trend line graph.

A focused scale is acceptable when it is transparent and does not hide data.

Calling descriptive intervals confidence intervals without qualification

These intervals do not account for the NHANES complex survey design.

Showing only the mean figure

Means can hide distributional spread, extreme values, group size, and missingness.

Saving only PNG

PNG is useful for digital display, while PDF and SVG provide scalable vector outputs.

Embedding a figure that has not been generated

The image links in this lesson will work only after the pipeline creates the corresponding PNG files.

Assuming publication styling proves publication validity

Visual quality and statistical validity are separate requirements.

Checkpoint

Confirm:

Knowledge check

NoteWhy use both color and shape for the trend lines?

Using both improves accessibility and allows groups to remain distinguishable when printed in grayscale or viewed by readers with color-vision differences.

NoteWhy remove gridlines?

Removing gridlines creates a cleaner publication-style figure and reduces visual competition with the data. Axis ticks and labels still provide scale information.

NoteWhy include the unweighted caveat inside the principal figure?

Figures are often copied outside their original report. An in-figure caveat helps preserve the analytical limitation even when the figure is viewed separately.

NoteWhy create a distribution figure in addition to the mean trend?

Means can conceal skewness, variation, extreme observations, and differences in the shape of the underlying data.

NoteIs a focused y-axis misleading?

Not automatically. It is acceptable when all data are shown, tick values are clear, the scale is selected transparently, and the figure does not imply that zero is the relevant reference point.

NoteAre the figures ready for final journal submission?

The visual presentation is close to manuscript quality, but inferential NHANES publication requires the correct survey weights, design variables, variance estimation, and analysis-specific methodological review.

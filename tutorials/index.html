R Tutorials for NHANES Laboratory Data

Guided courses for building, validating, and analyzing component-specific NHANES laboratory pipelines

The tutorial catalog for the NHANES Laboratory Data Pipeline in R.

Tutorial philosophy

Each tutorial is designed to teach:

  • the structure of the relevant NHANES component;
  • the scientific decisions behind the pipeline;
  • the R code used to implement those decisions;
  • expected outputs;
  • validation checks;
  • survey-design implications;
  • limitations.

The tutorials do not present code as a black box.

Available tutorial

Reproducing the NHANES CBC and Demographic Data Pipeline in R

Level: Complete beginner

Coverage: 1999–2000 through 2017–2018

Estimated guided time: 2–3 hours

Tools: R, Visual Studio Code, Quarto

The course covers:

  • software installation;
  • R execution in VS Code;
  • project organization;
  • package management;
  • NHANES source-file mapping;
  • XPT downloads;
  • CBC and Demographic integration;
  • duplicate detection;
  • second-examination handling;
  • merge validation;
  • descriptive analysis;
  • visualization;
  • troubleshooting.

Standard tutorial structure

Every future tutorial should include:

  1. course scope;
  2. prerequisites;
  3. learning objectives;
  4. component background;
  5. source-file mapping;
  6. stepwise R code;
  7. expected results;
  8. validation;
  9. survey-weight guidance;
  10. quizzes;
  11. complete script;
  12. troubleshooting;
  13. next steps.

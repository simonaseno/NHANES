Foundations Overview

Understand the core ideas that make NHANES analysis defensible

Explore NHANES data structure, survey design, survey weights, and combining cycles through concise explanations, visual pathways, and interactive checks.

Before analysis comes structure

NHANES data are powerful because they combine interviews, examinations, laboratory testing, and survey methodology in one national program.

That strength also creates complexity.

A defensible analysis depends on understanding four foundations:

  • how NHANES data are organized;
  • how participants are sampled;
  • how survey weights work;
  • how multiple cycles should be combined.

A participant may appear across several files within the same survey cycle.

The central participant identifier is:

SEQN

A reliable merge depends on knowing:

  • which file belongs to which cycle;
  • which component contains the needed variable;
  • whether the relationship is one-to-one, one-to-many, or supplementary;
  • whether the same variable name has the same meaning across cycles.

Core principle: Never merge files only because they contain the same identifier. First verify what one row represents in each file.

NHANES is not a simple random sample.

Participants are selected through a complex multistage design involving:

  • geographic sampling;
  • primary sampling units;
  • strata;
  • household selection;
  • person-level selection;
  • deliberate oversampling of selected groups.

Ignoring this structure can produce incorrect standard errors and misleading confidence intervals.

Core principle: The sample design affects uncertainty, not only the point estimate.

A survey weight reflects how many people in the target population a participant represents.

The correct weight depends on:

  • the variables used;
  • the examination or laboratory component;
  • the eligible subsample;
  • the number of cycles combined.

Core principle: Use the weight associated with the smallest analytic subsample represented in the analysis.

Combining cycles can increase sample size and analytical stability.

It also requires careful decisions about:

  • variable harmonization;
  • method changes;
  • eligibility;
  • cycle labels;
  • weight adjustment;
  • interpretation over time.

Core principle: Appending rows is easy. Establishing comparability is the real analytical task.

A practical example

Suppose you want to examine hemoglobin using CBC and Demographic data from 1999–2018.

You would need to answer:

  1. Which CBC file is primary for each cycle?
  2. Is there any supplementary or repeat examination file?
  3. Which Demographic variables are required?
  4. Is SEQN unique in each source?
  5. Are hemoglobin units and methods comparable?
  6. Which survey weight is appropriate?
  7. How should the weight be adjusted across ten cycles?
  8. Are the results descriptive or nationally representative?

This is the logic underlying the CBC and Demographic pipeline course.

Common analytical mistakes

WarningMistake 1: Treating every file as one row per participant

Some files may contain repeat records, supplementary examinations, or event-level data.

WarningMistake 2: Using any available survey weight

Weights are component-specific and sample-specific. An available weight is not automatically the correct weight.

WarningMistake 3: Combining cycles without checking comparability

Variable names, methods, units, eligibility criteria, and documentation may change across cycles.

WarningMistake 4: Calling unweighted summaries national estimates

Unweighted descriptive summaries describe the analytical records, not necessarily the U.S. population.

Quick knowledge check

NoteWhat is the main participant identifier used across NHANES files?

SEQN

NoteWhy are strata and PSUs important?

They are part of the sampling design and are needed for valid design-based variance estimation.

NoteDoes the largest available sample weight always apply?

No. The appropriate weight depends on the variables and the smallest eligible analytic subsample.

NoteIs combining cycles only a row-binding task?

No. It also requires harmonization, comparability review, and correct weight adjustment.

Foundation summary

Before analyzing NHANES data, establish:

what each record represents
how the sample was selected
which weight matches the analysis
whether cycles are comparable

These decisions determine whether the final result is merely computationally successful or scientifically defensible.

Reproducible workflows for NHANES laboratory data

From public-use files to validated analytical datasets.

Each pipeline translates a scientific question into a documented, reproducible workflow for finding, downloading, validating, combining, analyzing, and reporting NHANES data.

Source-aware Files, cycles, roles, URLs, and provenance
Validation-first Keys, rows, variables, missingness, and joins
Laboratory-informed Methods, units, eligibility, and comparability
Reusable Scripts, outputs, documentation, and figures

What every pipeline is designed to do

Discover Identify cycles, components, files, and variables.
Acquire Download and preserve official source files.
Validate Inspect structures, keys, records, and completeness.
Integrate Harmonize cycles and merge components safely.
Report Create datasets, tables, figures, and evidence.

The standard for every pipeline

1

Transparent sources

Every source file, survey cycle, URL, local path, and file role should be documented.

2

Explicit scientific decisions

Primary files, supplementary records, eligibility rules, and harmonization choices should be visible.

3

Validation before analysis

Keys, row counts, joins, missingness, ranges, and cycle coverage should be checked systematically.

4

Reusable outputs

Processed datasets, tables, figures, dictionaries, logs, and validation records should be saved.

Pipeline architecture

  • Configuration
  • Acquisition
  • Validation
  • Integration
  • Analysis and reporting

Configuration files define:

  • survey cycles;
  • components;
  • source files;
  • source URLs;
  • file roles;
  • expected variables;
  • local destinations.

Acquisition functions:

  • download source files;
  • preserve raw files;
  • record status;
  • calculate hashes;
  • document provenance.

Validation functions inspect:

  • file existence;
  • import success;
  • dimensions;
  • variables;
  • participant keys;
  • duplicate records;
  • missingness;
  • expected relationships.

Integration functions:

  • add cycle provenance;
  • harmonize names and classes;
  • combine compatible cycles;
  • preserve supplementary files;
  • merge components;
  • validate row relationships.

Final stages create:

  • analysis-ready datasets;
  • descriptive summaries;
  • figure datasets;
  • exported figures;
  • dictionaries;
  • execution logs;
  • reproducibility evidence.

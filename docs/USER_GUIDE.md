# User guide

[Return to the repository overview](../README.md)

## Environment and installation

Use a local checkout and run commands from its root. The R project declares R
4.1 or newer, while the lockfile records R 4.5.1. Using the recorded version
reduces environment differences. This is not an installable package: do not use
`install.packages("nhanespipeline")` or `devtools::install_github()` as the setup
procedure.

```bash
git clone https://github.com/simonaseno/NHANES.git
cd NHANES
Rscript -e 'renv::restore()'
Rscript tests/run_tests.R
```

Dependency restoration and the first acquisition require internet access.
Packages are installed in the project's renv library. The pipeline currently
uses `digest`, `dplyr`, `haven`, and `httr`; use the lockfile rather than
manually choosing replacement versions.

## Command-line interface

```bash
Rscript scripts/run_pipeline.R --catalog=config/nhanes_files.csv \
  --cache-dir=data/raw --output-dir=data/derived \
  --refresh=true --write-csv=false
```

| Option | Default | Meaning |
| --- | --- | --- |
| `--catalog` | `config/nhanes_files.csv` | Reviewed source catalog CSV |
| `--cache-dir` | `data/raw` | Local XPT cache |
| `--output-dir` | `data/derived` | Regenerated datasets and manifests |
| `--refresh` | `true` | Download again; `false` reuses a non-empty cached file |
| `--write-csv` | `false` | Write CSV copies as well as RDS datasets |

Options must use `--name=value`. Boolean values are `true` or `false`
(case-insensitive). Unknown options and invalid values stop execution.
The script resolves the project root from its own path; relative option paths
are interpreted against that root.

A cache-only rerun still downloads files absent from the cache. Neither mode
automatically changes the reviewed catalog's expected row counts.

## Read and check the outputs

```r
cbc <- readRDS("data/derived/cbc_primary_1999_2018.rds")
merged <- readRDS("data/derived/cbc_demographics_1999_2018.rds")
stopifnot(nrow(cbc) == nrow(merged))
stopifnot(!anyDuplicated(merged[c("SEQN", "cycle")]))
read.csv("data/derived/validation.csv")
read.csv("data/derived/provenance.csv")
```

The joined dataset uses suffixes `_cbc` and `_demo` for column names present in
both components. Its primary-CBC row count must remain unchanged.

The validation manifest reports dimensions, distinct `SEQN` counts and repeated
`SEQN` rows. The enforced merge key is `SEQN + cycle`; a repeated participant
identifier summary is not a replacement for that key check.

The provenance manifest identifies every source by URL and SHA-256. Its
`retrieved_at_utc` field is generated when the manifest is built. For cached
runs it is **not the original download time**. Preserve the manifest and the
exact release version alongside outputs when reporting reproducibility.

RDS preserves R classes and attributes. CSV is convenient for other tools but
does not preserve those attributes. The production entry point does not generate
the figures and extended teaching audit tables shown in the course.

## Course examples versus production software

The [course](https://simonaseno.github.io/NHANES/tutorial/) teaches an expanded
workflow that learners assemble as `nhanes_pipeline.R`. That file is a learner
output, not a committed executable in this repository. Some lesson examples add
labels, analyses, figures, and extra reports.

For the implemented, tested software, use `scripts/run_pipeline.R` and the
outputs listed in the repository README. Do not expect lesson-specific objects
or report files to be generated by that entry point.

## Scientific interpretation

Keep the unweighted 2001–2002 second examination separate from primary CBC.
Do not append it to the primary survey analysis table. The pipeline does not
select a universal pooled survey weight or fit a survey model. Review official
eligibility, laboratory methods, units, missingness, and analytic weight guidance
for every question. Retaining variable names does not by itself harmonize their
scientific meaning across cycles.

## Troubleshooting

| Symptom | Next action |
| --- | --- |
| `Rscript` is not found | Install R and make its executable available on PATH. |
| Required package is unavailable | Restore renv from the repository root; check restoration errors. |
| Download fails or times out | Check network access and the catalog's official CDC URL, then rerun. |
| A source row count differs | Stop and review CDC revisions; do not bypass the count check. |
| Duplicate or missing keys | Inspect the source and record level; do not silently deduplicate. |
| Expected lesson figure is absent | Run the learner's course workflow; it is not a production output. |
| Scheduled refresh stops | Follow the maintenance guide; the repository itself is not being deleted. |

For help, open an issue with the commit/version, `R.version.string`, command,
error, and affected source identifier. Do not upload credentials or non-public
data.

## Build the educational site

Install Quarto separately, restore the R environment, and run:

```bash
quarto render
```

The site is written to `_site/`. Code snippets in the lessons describe a teaching
workflow; a successful site render is not proof that every lesson's expanded
analysis has been executed.

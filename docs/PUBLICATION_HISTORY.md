# Publication history and publisher

The original work was published by **Praxis Global Institute** on **July 16, 2025**.
Simon Aseno is the author. Zenodo provides archival hosting and DOI registration
for the later software release.

## Evidence for the original date

The [original published HTML](https://github.com/simonaseno/NHANES/blob/d503049d688c819698ece7c52744fce534360aee/docs/NhanesDownloadScripts.html)
contains both `<meta name="dcterms.date" content="2025-07-16">` and a displayed
**July 16, 2025** date. Its suggested citation identifies the original work as:

> Aseno, S. (2025). *NHANES CBC and Demographic Data Downloader: A Structured Ingestion Pipeline for Pre-Pandemic Trend Analysis (1999–2018)*.

That citation describes **Version 1.0**. The GitHub repository history begins
on July 17, 2025; this is later than the date in the published document.
The historical Quarto source used `date: today`, so rerendering it could change
the displayed date. The original rendered HTML is the evidence retained here.

Publisher attribution to Praxis Global Institute is confirmed by the author;
the historical document evidence establishes the date and original version.

## Later version and archival dates

The pipeline was revised in August 2026 and **v0.2.0** was released in October
2026. [Zenodo record 23309272](https://zenodo.org/records/23309272) archives that
later source version with DOI **10.5281/zenodo.23309272**.

The original publication date, later software-version release date, and archive
creation date describe different events. Recording the original 2025 publication
does not imply that the revised v0.2.0 source code existed in 2025.
